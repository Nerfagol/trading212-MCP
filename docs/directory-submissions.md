# Directory Submission Material

No third-party directory submission or promotional pull request is automated by
this repository.

## Submission-ready summary

> Strictly read-only Trading 212 MCP server for self-hosted portfolio and account access.

Repository: `https://github.com/Nerfagol/trading212-MCP`

Key facts: eight read-only MCP tools; Docker and QNAP deployment; optional OpenAI
Secure MCP Tunnel; Demo and Live Trading 212 environments; MIT licensed; no
trading or order-management implementation.

## Official MCP Registry

Follow [Release and MCP Registry readiness](releasing.md). The repository is
prepared for the official Registry, but publication remains a deliberate manual
owner action.

## MCP Directory

[MCP Directory's submission form](https://mcp.directory/submit) accepts a GitHub
repository URL, an optional package URL, and a short description. Use the summary
above after the release image is public.

## awesome-mcp-servers

The actively maintained
[`wong2/awesome-mcp-servers`](https://github.com/wong2/awesome-mcp-servers)
repository directs projects to the submission form at
[`mcpservers.org/submit`](https://mcpservers.org/submit) instead of accepting
listing pull requests. Review its current rules before submitting; no promotional
PR is part of this release process.
